# Security policy

Read [the threat model](docs/SECURITY_MODEL.md) before allowing private code or host checks. Do not post secrets in issues or reports. For a vulnerability, contact the project maintainer privately through their authenticated GitHub profile; no security inbox or response SLA is invented by this distribution.

Stop the service, revoke exposed PATs and rotate the separate MCP token when credentials are compromised. Do not weaken branch rules to make a push succeed. This source distribution has offline verification, not an independent security audit or Windows/live-GitHub certification.
