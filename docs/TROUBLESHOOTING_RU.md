# Устранение ошибок

Актуальная настройка, статусы, ключ, YAML, перенос и автозапуск описаны в
[USER_GUIDE_RU.md](USER_GUIDE_RU.md). Не задавайте runtime key постоянно в окружении Windows.
Не удаляйте lock-файлы живого процесса. Не завершайте неизвестные процессы ради порта.

Если profile doctor завершается ошибкой, автоматические повторы прекращаются.
После исправления ключа/профиля нажмите «Запуск». Тайм-аут допускает ограниченные повторы.
Исправление команды и сохранение YAML выполняются локально и не требуют ключа или сети.
Проверка профиля использует ключ из поля пароля, если он введён, иначе — из хранилища ОС.
Для последующих запусков ключ нужно сохранить кнопкой «Сохранить».

При MCP_COMMAND: «Настройка запуска» → «Подставить команду текущей программы» →
«Исправить команду MCP» → «Сохранить». Это заменяет старую команду uv/Python
на команду текущего EXE. Само исправление ещё не подтверждает соединение с облаком.

Поле stdio редактируется; пользовательская команда сохраняется в JSON и выбранном
YAML при сохранении настройки. Пустое значение настройки tunnel_stdio_command
означает автоматическую команду текущей программы. После переноса EXE повторите исправление.

Копируемая диагностика содержит error_code и exit_code, но не сырой stderr:
MCP_COMMAND — неверная команда; TUNNEL_KEY_MISSING — нет ключа в хранилище;
TUNNEL_MISSING — файл клиента не найден; TUNNEL_EXECUTABLE — файл не запускается;
DOCTOR_FAILED — клиент отклонил проверку; DOCTOR_TIMEOUT — время проверки истекло;
EXTERNAL_TUNNEL — уже работает внешний клиент; PROCESS_EXITED — процесс завершился.
Причина и результат операции отображаются внизу окна настройки, вне области прокрутки.
